# AI-Vibe-Checker

An AI-powered sentiment analysis tool built with Python and Hugging Face Transformers.

## Features
- Analyzes text sentiment (positive or negative)
- Provides confidence scores
- Interactive CLI loop for real-time text analysis

## Requirements
- Python 3.8+
- PyTorch
- Hugging Face Transformers

## Installation
```bash
pip install -r requirements.txt
```

## Usage
```bash
python app.py
```
